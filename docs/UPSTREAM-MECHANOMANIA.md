# Mechanomania 上游归属与许可边界

Motiquies 服务器的大量内容来源于 **Mechanomania**。该上游关系由服务器维护者明确指出，应作为来源追溯的起点。

[官方项目页](https://www.curseforge.com/minecraft/modpacks/mechanomania)列出的作者是 **MoePus**；[官方许可页](https://www.curseforge.com/minecraft/modpacks/mechanomania/license)在2026-11-16核查时声明 **All Rights Reserved**。这是当前公开页面的记录；准确采用的历史版本、原始整合包指纹和当时适用的条款仍需固定，不能用当前最新版代替服务器基线。

## 当前复核与复现目标

已公开的组件仍须结合这项上游关系复核其源码归属，重点核对性能 fork、历史补丁、搬运代码及其来源声明。组件已有的逐文件构建证据继续保留；它们不证明整个 Mechanomania 包的分发权，也不自动完成上游包中新增代码的权利追溯。没有发现具体问题前，不通过覆盖历史记录制造已审结论；发现问题则记录准确路径、来源和处理结果。

本次没有将完整 Mechanomania、其 KubeJS 目录、世界生成数据包、结构、纹理或其他整包资源导入公开仓库。未闭合部分继续单列，不能归入本仓库根 MIT。所需外部上游输入记录合法获取位置和内容指纹，只有获得相应权利的源码、差异或独立工具才能公开。

最终公开复现材料应固定上游包及独立组件输入，再明确列出 Motiquies 的后续修改、构建与验证步骤。由使用者提供上游原件本身不会消除代码、素材或派生内容的授权问题。当前完整服务器复现和本次上游归属复核均未完成。
