# 复现范围与尚未关闭的缺口

目标是完整复现服务器的全部定制修改。[组件登记](../registry/components.json)列出的 30 组模块和独立工具均有源码、许可、固定输入和实际重复构建记录。服务器完整复现还需要补齐下表的内容。

## 已有证据如何解读

- 运行时 class 相同：表示与指定参考产物逐字节比较相同，必须结合组件注明的“候选 / 服务端定制 / 历史工具”范围。
- 两次构建相同：表示在记录的相同 JDK、Python 和锁定依赖下，两个新输出目录生成相同字节。
- 原 JAR 全部相同：仅在有完整产物指纹证明时才这样描述。新增许可、作者声明或不同 ZIP 打包方式会改变整包哈希。
- 游戏验收：单独记录，不由上述源码检查或 CI 自动推断。公开源码不是生产更新通知。
