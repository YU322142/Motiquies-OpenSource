# 来源与署名规则

每项定制修改分别登记基底、原作者及原许可、Motiquies 后续实际差异、构建/输入指纹和验证范围。保留原 LICENSE、版权头及署名；根许可只适用于有权按该许可授权的部分。

| 来源类别 | 署名与维护方式 |
| --- | --- |
| Mechanomania 整合包内容 | 标注上游整合包及官方署名 MoePus；原文件中有更具体作者时保留，不将所有独立组件都归给同一作者 |
| 上游或历史合并包继承文件 | 记录继承关系和文件指纹；相同字节不单独证明作者身份，合并包也不冒充官方原包 |
| 独立模组及其 fork | 分别保留具体上游与 fork 的作者、版本、代码/素材许可和真实改动 |
| Motiquies 新增修改 | 只对有证据的新增部分作此归属；原组件内容继续保留原作者和条款 |
| 新写的独立重建工具 | 明确它是新实现及采用的输入，不称作已找回旧 producer，也不据此取得旧代码版权 |
| 来源或公开权限待核 | 如实登记待核；公开材料不得嵌入尚未批准的正文、资源、编码副本或派生重建配方 |

维护者报告的 Mechanomania 使用、修改和整合包分发授权，与公开源码许可分别记录。合法获取的外部输入可由操作员提供；公开复现材料仍须核对其中的差异、代码及资源是否有权公开。哈希/构建通过只证明对应技术事实。

逐文件私有清单与凭据、玩家数据和生产运行文件不随公开仓库发布。公开来源元数据仅描述经复核的必要版本、出处与权利边界。完整服务器复现及所有权属审计仍未完成。
