# Recipe Set Diagnostic

NeoForge 1.21.1 diagnostic mod that reports recipe-set state while validating
the migrated pack. It does not alter player data or world saves.

Build with Java 21:

```text
gradlew.bat clean check --no-daemon
```

License: MIT.
