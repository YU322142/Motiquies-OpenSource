This producer modifies exactly SessionConfig.getValue(String) and
FullDataSourceRequestHandler.queueWorldGenForRequestMessage by prepending
conditional instruction sequences. With Java property motiquies.dh.cacheOnly
true, distant-generation eligibility is advertised but requests are routed
to existing LOD synchronization instead of queued world generation. Without
that property, original method instructions remain the fall-through path.
The actual deployed property state was not inspected and remains UNKNOWN.

The output archive is a historical modified Distant Horizons build, not an
official unmodified release. This notice and CORRESPONDING-SOURCE.md must
accompany any handoff. The producer preserves original archive notices/assets,
changes only the two class contents, and does not insert a new in-archive
notice because historical byte identity is the explicit reproduction target.
No output binary is published by this source export. Any distribution of a
modified upstream binary needs its own LGPL/GPL/source/asset review.

nothing and enables no JVM property. Prior private probes are not included.
