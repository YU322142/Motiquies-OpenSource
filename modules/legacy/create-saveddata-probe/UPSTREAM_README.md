# Create SavedData Probe

Small NeoForge 1.21.1 diagnostic mod used to inspect Create SavedData during
migration validation. It does not contain worlds, player data, or third-party
JARs.

Build with Java 21:

```text
gradlew.bat clean build --no-daemon
```

License: MIT.
