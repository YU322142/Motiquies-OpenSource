# POI Migration Diagnostic

Minimal NeoForge 1.21.1 diagnostic mod for checking point-of-interest state
after a world migration. It is tooling only and contains no world snapshot.

Build with Java 21:

```text
gradlew.bat clean check --no-daemon
```

License: MIT.
