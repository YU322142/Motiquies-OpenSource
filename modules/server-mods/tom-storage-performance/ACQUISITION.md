# External compiler inputs

The 143 entries in dependencies.lock.json are complete and ordered. Supply them externally; these tools perform no network request. A matching filename/version is insufficient: every SHA256 must match. Dependencies keep their original terms and are not relicensed or redistributed here.

Use a legally provisioned Minecraft 1.21.1 / NeoForge 21.1.241 client development SDK. The official installer/artifact index is https://maven.neoforged.net/releases/net/neoforged/neoforge/21.1.241/ ; official Minecraft installation is https://www.minecraft.net/download . The SDK's generated client SRG and NeoForge patched client archives are pinned parents in compiler-profile/profile.json. They are not supplied by this repository, and independent installer regeneration of these exact generated bytes has not been verified here. The current 21.1.241 compiler context is not asserted to be the historical declared 21.1.219 context.

For each SDK library entry, the Maven-relative path/version/classifier is recorded in the lock. Minecraft launcher libraries normally come from https://libraries.minecraft.net/ ; NeoForge artifacts from https://maven.neoforged.net/releases/ ; other public Maven artifacts may come from https://repo.maven.apache.org/maven2/ . Use the official launcher/installer's dependency routing and verify the pinned bytes rather than substituting a same-name artifact.

Supported SDK layouts are: Maven-relative files directly under the supplied root, or under libraries/, .minecraft/libraries/, or original/.minecraft/libraries/. The six additional SDK mod API files may be directly under the root, mods/, or game/mods/. Their exact filenames/pins and publisher project routes are recorded per entry: Architectury 13.0.11 NeoForge, Cloth Config 15.0.140 NeoForge, Curios 9.5.1+1.21.1, Jade 15.10.6 NeoForge, JEI 19.44.0.403 and Polymorph 1.1.0+1.21.1. Select the exact named published version; unresolved route/byte differences must not be silently replaced.

The separate API directory contains the nine exact files with fixed public URLs in the lock: REI api/neoforge/default-plugin 16.0.799, EMI 1.1.19+1.21.1 API, Sophisticated Core 1.4.23.1664, Sophisticated Storage 1.5.36.1606, The One Probe file5502323, Vivecraft file6060487, and JetBrains annotations24.1.0. These are compiler inputs only; no dependency main or annotation processor is executed.

The reference JDK is Eclipse Temurin 21.0.10+7 Windows x64 HotSpot: https://github.com/adoptium/temurin21-binaries/releases/tag/jdk-21.0.10%2B7 . Its javac version, executable and complete relative-file tree digest are locked. A different platform/toolchain needs its own explicitly reviewed lock; no automatic fallback changes the reference. Python standard-library tooling is used; the observed compiler-derivative archive profile was generated with CPython3.14.6 / zlib1.3.1.zlib-ng. Expected complete child archive hashes fail closed if another ZIP implementation changes the child bytes.

Keep all SDK/API/JDK/compiler children and build/test outputs outside the source repository. Source-only compilation does not require any PNG or runtime data file, and does not establish a complete mod archive, asset rights or gameplay acceptance.
